# Styly

تطبيق تنسيق هدوم الدولاب. البيانات والصور بتتخزن على الموبايل نفسه (IndexedDB).

## المميزات
- إضافة قطعة بالكاميرا أو المعرض أو ملف PNG (بخلفية شفافة من برنامج تاني)، مع استخراج اسم اللون تلقائيًا
- محرك تنسيق ألوان: تقييم تناسق الطقم، "الأنسب للباقي"، وفلتر نوع الطقم (كاجوال / رسمي / رياضي / خروجة)
- جدول أسبوعي: طقم لكل يوم
- نسخة احتياطية: حفظ واسترجاع كل الدولاب في ملف واحد (زرار السهم في أعلى الشاشة)

## تحميل وتحديث التطبيق
آخر نسخة دايمًا على الرابط ده، من غير زيب ولا تسجيل دخول:

`https://github.com/shawady6/styly/releases/latest/download/Styly.apk`

ثبّته فوق النسخة الموجودة. التحديث **مش بيمسح البيانات** طالما التوقيع ثابت (شوف تحت).

## إعداد مرة واحدة: مفتاح التوقيع
عشان كل نسخة جديدة تتثبّت فوق القديمة، لازم تتوقّع بنفس المفتاح:

1. افتح الريبو على GitHub، ثم **Settings** ثم **Secrets and variables** ثم **Actions**.
2. اضغط **New repository secret**.
3. الاسم: `STYLY_KEYSTORE_B64`
4. القيمة: محتوى ملف `styly-keystore-base64.txt` كله.
5. بعدها شغّل **Actions** ثم **Build APK** ثم **Run workflow**.

احتفظ بملف `debug.keystore` في مكان آمن (Drive). لو ضاع المفتاح، هتحتاج تمسح التطبيق وتبدأ من نسخة احتياطية.

لو الـ secret مش موجود، الـ build بيعمل ملف اسمه `styly-temp-apk-DO-NOT-INSTALL`. ماتثبّتوش.

## تجربة سريعة (PWA)
ارفع مجلد `www/` على GitHub Pages وافتح الرابط من Chrome ثم "Add to Home Screen".

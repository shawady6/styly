# Styly

تطبيق تنسيق هدوم الدولاب. البيانات والصور بتتخزن على الموبايل نفسه (IndexedDB).

## المميزات
- إضافة قطعة بالكاميرا أو المعرض أو ملف PNG (بخلفية شفافة من برنامج تاني)، مع استخراج اسم اللون تلقائيًا
- محرك تنسيق ألوان: تقييم تناسق الطقم، "الأنسب للباقي"، وترشيح أطقم بتتعلم من اختياراتك
- فلترة الدولاب بالنوع
- تركيب طقم يدوي أو عشوائي وحفظه
- جدول أسبوعي: طقم لكل يوم

## بناء الـ APK
الـ build بيشتغل تلقائيًا مع كل push على `main` من تبويب **Actions**.
نزّل `styly-debug-apk` من الـ Artifacts، فك الضغط وثبّت `app-debug.apk`.

الأيقونة والـ splash في `resources/android/` وبتتطبق تلقائيًا في الـ workflow.

## تجربة سريعة (PWA)
ارفع مجلد `www/` على GitHub Pages وافتح الرابط من Chrome ثم "Add to Home Screen".
